# Mirrorly

ვიდეოზარში სხვები დაგინახავენ ისე, როგორც სარკეში ხედავ თავს.
მუშაობს Google Meet-სა და Zoom-ის ვებ-ვერსიაში (Chrome, Edge).

[English](README.md)

## დაყენება

1. ამ გვერდზე დააჭირე მწვანე ღილაკს **Code**, შემდეგ **Download ZIP**.
2. გახსენი ჩამოტვირთული ფაილი.
3. Chrome-ში გახსენი `chrome://extensions`.
4. მარჯვნივ ზემოთ ჩართე **Developer mode**.
5. დააჭირე **Load unpacked** და აირჩიე საქაღალდე `extension`.
6. ზედა ზოლში თავსატეხის ხატულით მიამაგრე **Mirrorly**.

## გამოყენება

1. გახსენი Google Meet და შედი ზარში.
2. დააჭირე Mirrorly-ის ხატულას და აირჩიე ორი პარამეტრი.
3. როგორ გხედავენ სხვები, ნახავ ტელეფონიდან იმავე ზარში შესვლით.
